# Demo Script

1. Start backend and frontend.
2. Open `http://localhost:5173`.
3. Show Setup and run the prepare preflight.
4. Create the seeded workplace safety course.
5. Generate the plan and point out the approval gate.
6. Edit one chapter title or duration, then approve.
7. Show Pipeline while the backend launches real Devin sessions.
8. Open Evidence Ledger and expand:
   - Course Request
   - Approved Plan
   - Lastenheft / Spec
   - Generated Devin Prompts
   - Devin Jobs
   - Status Events
9. Verify real Devin session IDs, branch names, commits, PR URLs, and transcript summaries.
10. Open Reporting Dashboard for LMS/compliance metrics.
11. Open Preview after hosting output is available.
